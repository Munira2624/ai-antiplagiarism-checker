 AI Anti-Plagiarism Checker

 About Project
This is a local web-based plagiarism checker that analyzes text similarity using a small internal database.

Users can enter text and the system compares it with stored content to detect possible plagiarism and similarity percentage.

---

 Features
- AI-based text similarity analysis
- Plagiarism percentage detection
- Internal database comparison
- Multilingual support (🇺🇿 Uzbek, 🇷🇺 Russian, 🇬🇧 English)
- Document upload and analysis
- Supports DOC, DOCX, PDF, and TXT files
- Clean and user-friendly interface

---

 Story Behind This Project
I created this project to explore how plagiarism detection systems work and to improve my skills in backend development, text analysis, and web technologies.

The project was developed as a learning and portfolio project for university applications and personal practice.

---

 AI / Analysis Logic
The system uses text comparison and similarity analysis techniques to identify matching content inside its local database.

It:
- Processes input text
- Compares it with stored documents
- Calculates similarity percentage
- Displays possible plagiarism results

 Technologies

- Local database
- Text similarity analysis
